# micro-research

Small, cheap experiments on how AI agents actually behave, each with its code, data and a research brief. Every study is in its own folder and can be rerun.

| # | Study | Question | Status |
|---|---|---|---|
| 01 | [Memory position](01-memory-position/) | Does an agent follow a stored preference less often depending on where it sits in its memory? | Done, Nov 2026 |
| 02 | [Memory routing](02-memory-routing/) | How should an agent choose which memories go into the prompt, so the right one gets used at the lowest cost? | Done, Nov 2026 |
